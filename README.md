# 주간 업무 일지 (개인 · 비공개)

`weekly-task-report` 스킬이 쓰고, 주간 업무 일지 뷰어 앱이 읽는 원본 모음.
뷰어 앱 저장소 안의 `data/` 에 클론해 두는 **독립 저장소**다 — 앱 저장소는 `/data/` 를 무시한다.

| 파일 | 누가 쓰나 | 내용 |
|---|---|---|
| `<YYYY>-W<주차>_<MMDD-MMDD>.md` | 스킬 | 한 주 = 파일 하나 |
| `products.json` | 뷰어 앱 `설정 → 제품 목록` (스킬도 새 제품을 덧붙일 수 있다) | 일지 대분류로 쓰는 제품 목록 + 분류 기준 |
| `notion.json` | `weekly-notion-sync` 스킬 (개발2팀만, 설정했을 때만 있다) | 노션 주간업무보고 동기화 설정 — 담당자 · 부서 |

- 커밋·푸시는 스킬이 기록할 때마다 자동으로 한다. 기록 전에는 항상 pull 부터 한다.
  앱에서 바꾼 `products.json` 도 다음 기록 때 함께 실려 간다.
- 줄끝은 파일마다 원래 것을 유지한다 (`.gitattributes` 의 `-text`).
